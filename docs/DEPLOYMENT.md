The FastAPI backend in `backend/` is **not deployed**. Without it the site runs in demo mode: recorded sample answers, all eight stages, no API key. The Live switch shows as unavailable.

## Architecture

`Browser → Vercel (Next.js, static) `

The page is prerendered static content. All lesson data for demo mode ships in the JavaScript bundle, so the site makes no API calls. When `NEXT_PUBLIC_API_URL` is set, the page also checks `GET <url>/api/health` and enables Live mode if the backend reports an API key.

## Deployment workflow

- Vercel is connected to the GitHub repository. A push to `main` builds and deploys to production; other branches get preview deployments.
- Vercel project settings: framework Next.js, **Root Directory `web`**, package manager from `web/pnpm-lock.yaml`.
- Check status: `vercel api "/v6/deployments?projectId=prj_aILfAe7JbkqAurKrY936K7icurV2&limit=5" --scope erics-projects-5864beb8`, or the Vercel dashboard.
- Roll back: `vercel rollback` or Instant Rollback in the dashboard.
- There is no database and no migration step.

## Configuration

| Variable | Where | Purpose |
| --- | --- | --- |
| `NEXT_PUBLIC_API_URL` | Vercel (not set) | Public URL of the backend for Live mode. Unset means demo mode only. Never put a secret here. |

Backend variables (`OPENAI_API_KEY`, `OPENAI_MODEL`, limits, `ALLOWED_ORIGINS`) are documented in `backend/.env.example` and only matter if the backend is deployed.

## Custom domain

`ai-visualized.ericzwierzynski.dev` is a Cloudflare DNS-only `CNAME` (not proxied) to the project's Vercel target `39f76440ce954e2e.vercel-dns-017.com`, like the other projects on this zone. Vercel issues the HTTPS certificate.

## Maintenance and limits

- Demo-mode content is generated by `backend/scripts/make_fixtures.py` into `web/src/lessons/ai-request/fixtures.json`; rerun it after changing sample answers.
- To enable Live mode in production, deploy `backend/` (for example on Render), set `OPENAI_API_KEY` there, add the site origin to `ALLOWED_ORIGINS`, and set `NEXT_PUBLIC_API_URL` on Vercel. The backend's rate limits are in memory per process, so review them before exposing a paid key publicly.
- Cost: none. Hobby plan limits apply.
