# Deploy AI Under the Hood

The Vercel project `ai-visualized` builds the Next.js app from the `web` root directory. The production branch is `main` and the custom domain is [ai-visualized.ericzwierzynski.dev](https://ai-visualized.ericzwierzynski.dev).

The lesson uses local fixtures and requires no environment variables. To verify a deployment, open the site, choose a question, and check that the request map advances and the Answer stage shows the prepared response.
